# Fastfetch branding

This directory reserves the configuration boundary for future ABS Linux Fastfetch branding. `logo.txt` is a compact placeholder logo; no fabricated system information or host output is stored here.

The eventual configuration may present the desktop layer as “ABS Linux” while truthfully reporting the Debian GNU/Linux 13 (Trixie) base and i3 session. It must not alter `/etc/os-release`.
