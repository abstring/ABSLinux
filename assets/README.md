# Assets

Future project-owned visual assets should be organized here by purpose, with `branding/` and `screenshots/` added when they contain real files. The existing root-level `ABSLinux_hero_ad.png` remains in place to preserve its committed path and is used as the README hero.

Original ABS Linux artwork is intended for `CC0-1.0`; third-party assets must retain their own license notices and must not be assumed to be CC0.
